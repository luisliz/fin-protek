# PLAYBOOK - the user's own rules

Skills that propose a trade read this file first. Only `/fin-protek:financial-review` changes it,
and only after the user approves each change. Every other skill proposes; it never writes here.

## Limits
Pointers to the limits in `portfolio/holdings.md` and any rule on how the user wants them applied.
Changed by: financial-review, with the user's approval.

## Sizing rules
How big a new position or an add may be, as a rule the user agreed to.
Changed by: financial-review, with the user's approval.

## Exit rules
Conditions decided in advance that trigger a trim or sale, such as a disproven thesis or a breached limit.
Changed by: financial-review, with the user's approval.

## Techniques to keep
Methods that a sound decision proved, each with the ledger entry that earned it.
Changed by: financial-review, with the user's approval.

## Techniques to stop
Methods that failed on process, each with the ledger entry that showed it.
Changed by: financial-review, with the user's approval.

## Behaviours to watch
Habits that cost the user money, such as anchoring on cost basis or selling after drops, each with the rule set for it in advance.
Changed by: financial-review, with the user's approval. Other skills name a behaviour and propose it here.

## Change log
One line per change: date, section, the change, the ledger entry that justified it.
Changed by: financial-review only, appended, never edited.
